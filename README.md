# Python CLI Projects – Intro to Programming Portfolio

This repository contains selected command-line Python programs developed for my NYU Introduction to Programming course.

Each project demonstrates core Python skills including control flow, loops, conditionals, string manipulation, input validation, and modular problem solving.

---

## Demonstrations

Run any file using:

python filename.py

---

## Featured Projects

pilot_training_performance_tracker.py  
Tracks pilot training performance across multiple exercise categories.  
Validates inputs, drops lowest scores when selected, computes averages, assigns letter grades, and prints a cohort performance report.

political_database_cli.py  
Menu-driven command-line database interface for navigating structured political data.

high_speed_rail_booking_system.py  
Simulates a rail booking system with seat availability logic and scheduling constraints.

string_encryption_engine.py  
Encrypts and decrypts user input using reversible string transformations.

login_security_validator.py  
Validates usernames and passwords using layered security rules.

chess_board_setup.py  
Programmatically generates and prints a chess board layout.

document_classification_analyzer.py  
Analyzes text structure and classifies document types.

officer_account_management_cli.py  
CLI account management system supporting record updates and user actions.
